# 🎬 StudioNamma Clone

A pixel-perfect, responsive front-end clone of the **StudioNamma** website built using HTML5, CSS3, and JavaScript. This project recreates the high-end creative agency experience with dynamic video embeds, custom cursors, smooth animations, and advanced layout techniques.

## 🚀 Live Demo

🔗 **Live Website**: [https://studionammaa.vercel.app/](https://studionammaa.vercel.app/)

---

## 📌 Key Features & Highlights

- **Dynamic Hero Section**: Interactive 3D cursor-following video card powered by GSAP.
- **Custom Cursor Engine**: Animated floating cursor with interactive hover labels (`Matera`, `Chance`, `Silvr`, `Intramuros`).
- **Services Video Hover**: Smooth fixed video preview player attached to service items.
- **Playground Card Popups**: Hover-activated blurred cover art with centered floating video popups.
- **Lenis Smooth Scroll**: Buttery-smooth inertial scrolling experience.
- **Official Typography**: Integrates StudioNamma's exact web fonts (`Mixtape Extra Condensed`, `Neue Montreal`, `GT Pressura Mono`).
- **Pixel-Perfect Logos**: Custom SVG client logos (`Qonto`, `Matera`, `CHANCE`, `SILVR`, `Alan`).

---

## 🛠️ Technologies Used

- **HTML5**: Semantic markup & media embeds (`video`, `svg`).
- **CSS3**: Custom properties, Flexbox, Grid, Glassmorphism, animations.
- **JavaScript (ES6+)**: Custom cursor logic, hover state management, DOM manipulation.
- **Libraries**:
  - [Lenis](https://lenis.darkroom.engineering/) (Smooth Scroll)
  - [GSAP](https://gsap.com/) (GreenSock Animation Platform)
